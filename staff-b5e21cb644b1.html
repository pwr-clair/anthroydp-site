▶김시흔호흡하는 잔여들

▶최가영나의 우육면 다이어리 · 우육면 트위스트

작품 · 기기 목록

  • 〈나의 우육면 다이어리〉 : 27인치 터치 일체형 PC 1대
  • 〈우육면 트위스트〉 : TV 2대 + 라즈베리파이 2대 (2채널 동기화)
  • 멀티탭 1개 — 두 작품 전원 ON/OFF. 커튼 뒤로 가려놓기
  • 키보드 1개 — 〈나의 우육면 다이어리〉 ON/OFF 및 비상용. 기둥 뒤에 보이지 않게 보관
  • 리모콘 1개 — 〈우육면 트위스트〉 TV 2대 ON/OFF. 기둥 뒤에 보이지 않게 보관
  • 의자 2개 — 〈우육면 트위스트〉 TV 앞에 간격을 두고 나란히 배치

개장 — ON

0. 멀티탭 전원 먼저 ON — [최가영 전원] 견출지를 붙인 가장 아래 버튼을 켠 뒤, 커튼으로 멀티탭 가려놓기

〈나의 우육면 다이어리〉 ON
  1. PC 모니터 좌측 옆면의 전원 버튼 누르기
  2. 화면이 켜지면서 자동으로 ‘YDP’ 계정에 로그인되고 게임이 구동됨
    게임이 안 뜨고 바탕화면이 나오면 → Ctrl+Alt+Del → 사용자 전환 → YDP 로그인(비밀번호 없음) → 게임 자동 구동
  3. 게임 화면을 한 번 터치하고 배경음악이 나오면 ON 완료. 키보드는 기둥 뒤에 보관.
〈우육면 트위스트〉 ON
  1. 리모콘으로 TV 2대의 전원 ON (리모콘은 TV 모니터 중앙 하단을 겨누어 조작)
  2. 리모콘 외부입력 버튼 → HDMI 1 (TV 2대 모두 동일하게)
  3. 음량 볼륨 각 30으로 맞추기
영상이 켜지는 도중(2분 이내)에 전원을 껐다 켜지 마세요. 두 채널이 동기화되는 중입니다.

폐장 — OFF

〈나의 우육면 다이어리〉 OFF

Ctrl+Alt+Del → 사용자 전환 → 오른쪽 하단 전원 아이콘 터치 → 시스템 종료
(‘다른 사용자가 사용 중…’ 메시지가 나와도 종료 진행)

전원 코드를 뽑거나 멀티탭을 내려서 강제 종료하면 안 됩니다. 윈도우가 손상될 수 있습니다.
〈우육면 트위스트〉 OFF

리모콘으로 TV 2대의 전원 OFF → 마지막에 멀티탭 [최가영 전원] 버튼 OFF

관람객 응대 — 조작 안내

〈나의 우육면 다이어리〉

  • 손가락으로 화면을 직접 만지면 됩니다. 마우스·키보드는 필요 없습니다.
  • 오른쪽 위 한 / 繁 / EN 버튼으로 언어를 바꿀 수 있습니다.
  • 오른쪽 위 다시 시작 버튼을 누르면 처음부터 시작합니다.
  • 화면 오른쪽 ? 버튼에 게임 설명이 있습니다.

일일 점검 · 이상 시 대처

〈나의 우육면 다이어리〉
작품(터치모니터 PC) 외에는 책상 위에 아무것도 올리지 않도록 해주세요. 특히 가방 · 음료 · 쓰레기. 기기 손상 우려가 있습니다.
  1. 화면이 멈췄다 / 반응이 없다 → 왼쪽 위 모서리 5초 → 전체화면 해제 → 재시작
  2. 관람객이 이상한 화면에 빠졌다 → 위와 동일
  3. 영상이 안 나온다 / 지도가 검다 → 위와 동일
  4. 소리가 안 나온다 → 오른쪽 위 ♪ 버튼이 🔇로 되어 있는지 확인하고 눌러서 켜기. 그래도 안 되면 윈도우 볼륨 확인.
  5. 소리를 꺼야 한다 → 오른쪽 위 ♪ 버튼 한 번 → 즉시 무음

무엇을 해도 안 된다 → 전원 버튼을 5초 이상 눌러 강제 종료 후 다시 켜기. 자동 로그인이라 알아서 복구됩니다.

〈우육면 트위스트〉
감상용 의자 2개가 제자리에 있도록 해주세요. 자리를 옮기거나 의자 위에 물건을 올리지 않도록 주의 부탁드립니다.
  1. 2분 이상 기다려도 오른쪽 화면에 아무것도 안 나온다 → TV 뒤쪽 두 컴퓨터를 잇는 랜선 확인. 양쪽 끝을 뽑았다 “딸깍” 소리가 날 때까지 다시 꽂기. 구멍 옆 작은 불이 켜지면 정상.
  2. 2분 이상 기다려도 양쪽 화면에 아무것도 안 나온다 → TV 입력이 HDMI 1인지 확인
  3. 영상이 자꾸 끊기거나 튄다 → 전원 어댑터가 헐겁지 않은지 확인. 계속되면 작가에게 연락.

위 방법으로 안 된다 → ① 두 컴퓨터 전원 모두 뽑기 → ② 10초 기다리기 → ③ 다시 꽂기 → ④ 2분 기다리기

★ 이건 고장이 아닙니다

〈우육면 트위스트〉
· 영상 중간중간 검은 화면에 글자만 나오는 장면이 있습니다.
· TV를 켠 직후 화면이 잠깐씩 멈췄다 움직입니다 — 두 화면의 시간을 맞추는 과정으로, 처음 30초 안에 한 번만 일어납니다.

〈나의 우육면 다이어리〉
· 터치 조작 없이 90초가 지나면 자동으로 리셋됩니다.
